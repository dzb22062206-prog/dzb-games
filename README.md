# DzB Games — стартовый сайт

Это первая статическая версия сайта DzB Games. Она сделана на HTML, CSS и JavaScript и подходит для бесплатного размещения на Cloudflare Pages.

## Что уже есть
- Главная страница с адаптацией под телефон и компьютер.
- Каталог игр с фильтрами.
- Демонстрационный магазин цифровых товаров.
- Лента новостей.
- Раздел «О студии».
- Данные игр, товаров и новостей вынесены в `content.js`, чтобы их было проще менять.

## Как открыть сайт на компьютере
Открой файл `index.html` в браузере. Для локальной разработки удобнее использовать расширение Live Server в Visual Studio Code.

## Как добавить свою игру
1. Экспортируй проект Godot в Web.
2. Скопируй папку экспорта в папку сайта, например `games/my_game/`.
3. В `content.js` найди массив `games` и добавь объект:
```js
{
  title: "Название игры",
  category: "browser",
  status: "PLAY NOW",
  description: "Описание игры.",
  art: "linear-gradient(135deg,#163e5b,#27235c)",
  symbol: "PLAY",
  url: "games/my_game/index.html",
  button: "Играть"
}
```
4. Проверь, что в папке экспорта есть `index.html` и все файлы Godot.

Важно: для Web-экспорта в настройках Godot включи нужные Web-пресеты. Некоторые функции Godot и сторонние расширения могут не поддерживаться в браузере — протестируй экспорт отдельно.

## Как изменить товары и новости
Открой `content.js`:
- `products` — товары магазина;
- `news` — публикации;
- `games` — игры.

Сейчас товары демонстрационные. Реальная оплата, доставка файлов, пользовательские аккаунты и защищённая админ-панель не подключены.

## Бесплатная публикация через Cloudflare Pages
1. Создай аккаунт Cloudflare.
2. Открой Workers & Pages → Create application → Pages.
3. Выбери вариант загрузки готовых файлов (Direct Upload), если он доступен в твоём аккаунте.
4. Загрузи содержимое папки проекта или ZIP согласно интерфейсу Cloudflare.
5. После публикации Cloudflare выдаст адрес `*.pages.dev`.

Перед публичным запуском проверь актуальные лимиты и правила бесплатного тарифа Cloudflare Pages.

## Что потребуется для следующего этапа
Для реального магазина и панели управления нужны серверная часть/база данных, безопасная авторизация, хранение файлов и подходящий платёжный провайдер. Не размещай секретные ключи в `script.js` или других публичных файлах. Платёжные подключения и договоры для несовершеннолетнего нужно оформлять только после проверки требований сервиса и с участием родителя.
